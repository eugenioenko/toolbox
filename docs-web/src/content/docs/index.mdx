## How it works

Toolbox provides **Sectool**, the command-line tool that connects your browser traffic to your coding agent through MCP.

<div className="workflow">
  <div><strong>1. Browse</strong><p>Sign in and use the application through Sectool’s proxy.</p></div>
  <div><strong>2. Investigate</strong><p>You and your agent inspect captured traffic and choose what to test.</p></div>
  <div><strong>3. Validate</strong><p>Replay modified requests, compare responses, and review the evidence together.</p></div>
</div>

## From captured requests to testable questions

<CardGrid>
  <Card title="Inspect real traffic" icon="magnifier">Query captured requests and responses, inspect cookies, and work from traffic produced by your authenticated browser session.</Card>
  <Card title="Replay and compare" icon="seti:json">Modify headers, query parameters, or JSON bodies. Compare flows to examine what changed.</Card>
  <Card title="Explore the API surface" icon="document">Extract endpoint references and available request shapes from captured JavaScript and HTML, or crawl from URLs and flows.</Card>
  <Card title="Observe callbacks" icon="signal">Use Interactsh-backed out-of-band sessions to collect DNS, HTTP, or SMTP interactions during testing.</Card>
</CardGrid>

## Start with a single binary

```bash
go install github.com/go-appsec/toolbox/sectool@latest
sectool mcp --proxy-port 8080 --workflow explore
```

Connect your browser to the proxy and your agent to the MCP endpoint. The [quickstart](./getting-started/quickstart/) walks through both. Prebuilt binaries are also available.

The native proxy supports HTTP/1.1, HTTP/2, and WebSockets. You can also [use Burp Suite](./integrations/burp/) as the HTTP backend or attach [sidecars](./integrations/sidecars/) for additional capabilities.
